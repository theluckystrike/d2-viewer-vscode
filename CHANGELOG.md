# Changelog

## 0.1.0

First release.

- Live D2 preview beside the editor, drawn by the bundled D2 engine (WebAssembly, version 0.7.0): no install, no network.
- Pan, zoom, Fit and 100%. A dark VS Code theme gets a dark D2 theme unless the file sets its own.
- A D2 theme picker and layout options (direction, sketch style) for one preview. No setting is written and no color theme is added.
- Errors as squiggles with the line number, in the Problems view and in the preview.
- Click a shape to jump to its line. A board list for layers, scenarios and steps. Copy as SVG.
- The D2 Diagram Viewer editor, an optional way to open a .d2 file as a diagram.
- Syntax highlighting with a grammar written for this extension.
- Zovo Pro tools with 1 free try each: Export PNG, PDF and SVG (every board, animated SVG), and Batch export to SVG with a watch mode.
