# Themes, layout and boards

- Theme opens a list of the 20 D2 themes. Automatic uses the theme of the .d2 file, or a light or dark D2 theme to match VS Code.
- Layout sets the direction of the diagram (down, right, left or up) and turns the sketch style on or off.
- Both are kept for this file in this workspace only. The .d2 file, your VS Code theme and your settings stay as they are.
- A diagram with layers, scenarios or steps shows a board list next to the file name. Pick a board to see it.
